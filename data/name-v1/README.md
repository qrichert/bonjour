# Bonjour Name Data v1

This directory describes the pinned statistical artifact used by
`bonjour` 0.1.0. The complete artifact consists of the twelve files
listed in `manifest.json`.

The artifact contains an MPHF-based index, 32-bit membership
fingerprints, and quantized aggregate given-name, surname-role, country,
and gender evidence. It contains no original source rows or name
strings.

The twelve binary constituents are intentionally excluded from the
crates.io package. Download `bonjour-name-data-v1.tar.zst` from the
matching GitHub release, or use a self-contained GitHub release binary.
